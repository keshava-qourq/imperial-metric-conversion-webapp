# Imperial metric conversion webapp

imperial to metric conversion webapp

Generated by the Quorq AI SDLC platform: the approved app design as a Vite + React SPA in
`frontend/`, every screen reviewed and approved, running on seeded sample data. No approved
technology stack calls for a backend, so this repository is frontend-only.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```
